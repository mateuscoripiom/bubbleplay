# BubblePlay

🇧🇷 Protótipo inicial de uma plataforma de streaming de vídeo (Node.js no backend, React no frontend) — catálogo, reprodução via FFmpeg. Foi o ponto de partida de um projeto bem maior, que hoje roda como uma aplicação privada em produção com integração a servidor de mídia, HLS adaptativo e armazenamento em nuvem.

🇬🇧 Early prototype of a video streaming platform (Node.js backend, React frontend) — catalog and playback via FFmpeg. This was the starting point for a much larger project, which today runs as a private production application with media-server integration, adaptive HLS, and cloud storage.

**Stack:** Node.js, Express, React, FFmpeg
